Things I've built

Featured · C++ / Systems

In-Memory Key-Value Store

C++ · cache with pluggable eviction
  • Lookup, insert and evict in O(1) average time by pairing a hash map with a doubly linked list written from scratch
  • Storage, eviction policy and interface in separate layers; LRU and FIFO plug into the same store
  • 33-check test suite and a 2M-request benchmark: LRU hit rate 68.5% vs 59.7% for FIFO on skewed traffic
C++STLOOPMake
// real usage from the repo KVStore<std::string, int> cache( 3, std::make_unique<LRUPolicy<std::string>>()); cache.put("a", 1); cache.put("b", 2); cache.put("c", 3); cache.get("a"); // a is now most recent cache.put("d", 4); // full: evicts "b", O(1) cache.get("b"); // std::nullopt (miss)
